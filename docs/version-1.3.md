# Version 1.3

Version 1.3.0 closes the roadmap that started with 1.2.5. It adds no new tool: it checks the whole app and brings the documentation together. Files stay in format 7, and 1.2.x installations update themselves.

## Version 1.3.0

- **Documentation in English**: every document in `docs/` is now written in English.
- **Full check**: type checking, ESLint, Prettier, the unit tests and the complete end-to-end suite pass on every system the installers are built for.

## What came before (1.2.5 to 1.2.10)

See [Version 1.2](version-1.2.md): movable panels and interface size, merging and grouping layers, the colour wheel picker and "no colour", brush creation (shapes from an image, Photoshop `.abr` brushes), sharing and installing brushes, and saving a project as a PSD that Photoshop and Affinity open.
